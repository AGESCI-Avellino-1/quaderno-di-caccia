# Segnalare un problema di sicurezza

Il Quaderno di Caccia contiene dati di minori, anche sanitari. Se trovi un problema di
sicurezza **non aprire una issue pubblica**: usa la segnalazione privata di GitHub, dalla
pagina **Security** del repository, **Report a vulnerability**
(<https://github.com/AGESCI-Avellino-1/quaderno-di-caccia/security/advisories/new>).

Scrivi cosa hai trovato, la versione (o il commit) e i passi per riprodurlo. Non usare dati
veri di persone: per le prove ci sono i dati inventati (`manage.py dati_di_prova`).

Le correzioni escono come nuove versioni nella pagina Releases; chi ha installato una copia
per il proprio gruppo aggiorna seguendo la guida di installazione.

## Reporting a vulnerability (English)

Please do not open a public issue. Use GitHub's private vulnerability reporting
(**Security → Report a vulnerability**) on this repository, with the version and the steps to
reproduce. Never include real personal data.
